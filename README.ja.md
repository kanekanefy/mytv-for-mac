# 我的电视（MyTV for Mac）

**Mac向けのライブTV視聴アプリ「我的电视」（＝私のテレビ）。オンデバイスAIによるリアルタイム翻訳字幕を搭載したIPTVプレーヤーで、すべてご自身のMac上で完全オフラインで動作します。**

## このリポジトリについて

これは個人プロジェクトの**配布専用リポジトリ**です。インストーラー・ドキュメント・スクリーンショットのみを置いており、**ソースコードは含んでいません**。作者からこのリポジトリのリンクを直接教えてもらった方は、[インストール](#インストール)まで読み進めれば十分です。

このアプリ本体に対するコードのPull Requestは受け付けていません（本リポジトリにはマージ先となるソースコードが存在しないためです）。ドキュメントや訳文の軽微な修正PRは歓迎します。詳しくは[CONTRIBUTING.md](CONTRIBUTING.md)を参照してください。困ったときは[SUPPORT.md](SUPPORT.md)、セキュリティに関する報告は[SECURITY.md](SECURITY.md)をご覧ください。

## 機能

| カテゴリ | できること |
|---|---|
| ライブ配信ソース | m3u / m3u8 / txt（tvbox形式）のプレイリストに対応。同名チャンネルは複数ソースを自動でまとめて統合し、内蔵の公開プレイリストにワンクリックで切り替え可能 |
| EPG（番組表） | 現在/次の番組をプログレスバー付きで自動取得・表示 |
| 再生 | libmpvによるハードウェアデコード（VideoToolbox）。1080iの自動デインターレース、アスペクト比のロック/自動引き伸ばしの切り替えに対応 |
| チャンネルロゴ | チャンネルロゴを自動でマッチングして表示 |
| リアルタイム翻訳字幕（オンデバイスAI） | 外国語の放送を中国語字幕に変換。処理はすべてオンデバイス推論で行われ、通信も音声のアップロードも発生しません |
| 同時通訳モード | 字幕とタイミングを合わせるため映像を数秒自動で遅延。ON/OFFの切り替え時もアニメーションでなめらかにつながり、映像が唐突に飛ぶことはありません |
| 二言語字幕 | 原文と訳文を同一画面に表示。レイアウトは2種類から選べます |
| チャンネル別の言語自動判定 | 言語を手動で選ぶ必要なし。視聴中のチャンネルが話している言語を自動で判定します |
| モデル比較 / ブラインド評価 | 2つの翻訳モデルを同一画面に並べて比較し、ブラインドA/B投票でデータを収集 |
| 外国語チャンネル（オプション） | iptv-org提供の公開ドキュメンタリー系外国語チャンネルのリストを内蔵。デフォルトはオフで、設定画面からワンクリックでON |

## システム要件

- macOS 26 以降
- Apple シリコン（M系チップ）搭載Mac。Intel Macには対応していません
- アプリ本体はディスク容量を約100MB使用します。リアルタイム翻訳機能は初回利用時にモデルの追加ダウンロードが必要です（詳細は下記）

## インストール

1. 本リポジトリの[Releases](../../releases)ページから、最新の`MyTV-for-Mac-x.x.x.dmg`をダウンロード
2. DMGを開き、「我的电视」を「アプリケーション」フォルダにドラッグ
3. **初回起動時はmacOSにブロックされます**（有料のApple Developer IDによる公証を受けていないため、Gatekeeperがこのアプリをまだ認識できません）。次のいずれかの方法で許可してください
   - アプリを**右クリック（またはControlキーを押しながらクリック）**→「開く」を選択 → 確認ダイアログでもう一度「開く」をクリック
   - または：「システム設定」を開く →「プライバシーとセキュリティ」→ 下にスクロールして「"我的电视"は開発元を確認できないため開けませんでした」という表示の行を探す →「このまま開く」をクリック
   - どちらの方法も選択肢が出ない場合は、ターミナルで次のコマンドを一度だけ実行してください
     ```bash
     xattr -dr com.apple.quarantine "/Applications/我的电视.app"
     ```
4. 以降は通常どおりダブルクリックで起動できます。この操作が必要なのは最初の1回だけです

より詳しい手順（よくあるエラーの対処表つき）は[docs/installation.md](docs/installation.md)を参照してください。

## プレイリストの初期設定

このアプリには公開IPTVプレイリスト（500以上のチャンネル）が最初から内蔵されているので、**セットアップなしでそのまま視聴を始められます**。

友人から自分専用のプレイリストURLを教えてもらった場合は、「我的电视」を開き、メニューバーの「我的电视」→「设置…」（設定）→「订阅源」（ソース）タブを選び、URLを貼り付けて「应用并刷新」（適用して更新）をクリックしてください。

BBC EarthやNational Geographicのような海外ドキュメンタリー系チャンネルを見たい場合は、設定 →「订阅源」（ソース）→「国际纪实 / 外语台」（海外ドキュメンタリー・外国語チャンネル）という項目を見つけてスイッチをオンにしてください（デフォルトはオフ）。これらは[iptv-org](https://github.com/iptv-org/iptv)が公開しているストリームです。

## リアルタイム翻訳字幕の使い方

1. チャンネル再生中に`Y`キーを押すか、メニューバーの「翻译」（翻訳）→「开启实时翻译字幕」（リアルタイム翻訳字幕をON）を選択します
2. **初回はモデルのダウンロードを求められます**（デフォルトの容量は約1.5GB。クラウドAPIではなく完全ローカルのGGUFモデルです）。設定 →「翻译」（翻訳）タブにモデルライブラリがあるので、好きなモデルを選んでダウンロードしてください。中国本土のネットワーク環境では、より速いModelScope（魔搭）ミラー経由のダウンロードが優先されます
3. ダウンロード完了後は自動で読み込まれ、数秒で字幕が表示されます。話されている言語（原文言語）はチャンネルごとに自動判定されますが、手動で指定することもできます
4. 処理はすべてオンデバイス（`llama-server`のサブプロセス＋Metalアクセラレーション）で実行されます。通信も音声アップロードもなく、クラウドAPIにも依存しません

## FAQ

**初回起動時に「開発元を確認できないため開けません」と表示されるのはなぜ？**
上の[インストール](#インストール)の手順3を参照し、右クリックで開くか、システム設定から一度だけ許可してください。個人開発者がApple公証サービスに料金を払っていないだけで、これは想定どおりの動作です。

**翻訳機能が使えない／`llama-server`が見つからないと表示される**
ローカル推論用のランタイムはあらかじめアプリ内に同梱されており、通常は追加のインストールは不要です。それでもエラーが出る場合は、問題を報告する際に「设置 → 调试」（設定 → デバッグ）ページに表示されるログのパス（デフォルトは`~/Library/Logs/MyTV/`）の内容を添えてください。

**知らないうちにデータを外部に送っていない？**
送っていません。翻訳の音声認識・文の区切り・モデル推論はすべてローカルで処理されます。通信が発生するのは、ご自身が設定したIPTV/EPGのURLへのアクセスと、翻訳モデルの初回ダウンロードだけです。詳しくは下記の[プライバシー](#プライバシー)をご覧ください。

**Intel MacやmacOS 25以前でも動く？**
動きません。macOS 26で新たに使えるようになったAPI（システムレベルの`SpeechAnalyzer`音声認識など）を利用しており、ビルドもApple シリコン版のみを提供しています。

**アイコンや名前がAndroidの「〇〇TV」的なプロジェクトに似ているのはなぜ？**
本アプリはSwift + SwiftUI + libmpvを使って一から書き直したmacOSネイティブ版です。機能や方向性の面ではAndroidのオープンソースプロジェクト[yaoxieyoulei/mytv-android](https://github.com/yaoxieyoulei/mytv-android)（MITライセンス）を参考にしていますが、コードは独自実装であり、移植版ではありません。

## プライバシー

- **翻訳機能は完全にオンデバイスで動作します**：音声認識（システムの`SpeechAnalyzer`）とテキスト翻訳（`llama-server`のサブプロセスで推論するローカルGGUFモデル）はすべてオフラインで処理され、音声や字幕テキストがアップロードされることはありません。クラウドの翻訳APIにも依存しません（設定画面でご自身がサードパーティのOpenAI互換エンドポイントを手動で設定した場合を除きます）
- **利用状況やテレメトリを作者のサーバーへ送信することはありません**：デバッグログはローカルに書き出されますが（パスは設定画面に表示されます）、あなたのMac内に留まるだけです
- アプリ自体には誰かの個人的なIPTVプレイリストは含まれていません。ご自身で用意するか、内蔵の公開ソースをご利用ください
