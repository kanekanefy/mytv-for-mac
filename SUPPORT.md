# 获取帮助

遇到问题时，建议按下面的顺序找答案：

1. **先看 README 的 [FAQ](README.md#faq)** —— 大多数"打不开""无法验证开发者""翻译用不了"这类问题都能在这里找到答案
2. **再看 [docs/installation.md](docs/installation.md)** —— 更详细的安装步骤和常见报错排查表
3. **搜索已有的 [Issues](../../issues)** —— 你遇到的问题很可能已经有人问过、也有答案了
4. **仍然没解决，提一个新 Issue**：
   - Bug 用「Bug 反馈」表单，功能想法用「功能建议」表单
   - Bug 反馈请附上 macOS 版本、Mac 芯片型号、App 版本；翻译功能相关的问题请附上日志（默认路径 `~/Library/Logs/MyTV/`）

## 关于代码贡献

本仓库不含源代码，也不接受功能/修复类 PR；如果你想帮忙改善文档措辞或修个链接，看 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 关于安全问题

如果你发现的是安全相关的问题（例如签名/校验和被篡改、依赖组件已知漏洞等），不要在公开 Issue 里贴细节，按 [SECURITY.md](SECURITY.md) 的方式报告。

# Getting Help

If something isn't working, try these in order:

1. **Check the [FAQ in the README](README.en.md#faq)** — most "won't open" / "developer cannot be verified" / "translation doesn't work" questions are answered there
2. **Check [docs/installation.md](docs/installation.md)** — a more detailed install walkthrough with a troubleshooting table
3. **Search existing [Issues](../../issues)** — someone may have already run into (and solved) the same thing
4. **Still stuck? Open a new Issue**:
   - Use the "Bug report" form for bugs, "Feature request" for ideas
   - For bugs, include your macOS version, Mac chip, and app version; for translation-related issues, attach the log (default path `~/Library/Logs/MyTV/`)

## About code contributions

This repository has no source code and doesn't accept feature/fix PRs. If you want to help fix documentation wording or a broken link, see [CONTRIBUTING.md](CONTRIBUTING.md).

## About security issues

If what you found is security-related (e.g. a tampered signature/checksum, a known vulnerability in a bundled dependency), don't post details in a public Issue — report it the way described in [SECURITY.md](SECURITY.md).
