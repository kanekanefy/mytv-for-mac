# 安装指南（详细版）

简版见根目录 [README.md](../README.md#安装)。这里补充每一步可能遇到的具体情况。

## 1. 下载

去 [Releases](../../releases) 页面，下载最新的 `我的电视-x.x.x.dmg`。

## 2. 安装

双击打开 DMG，把「我的电视」图标拖到「Applications」图标上即可。DMG 窗口关闭后可以把它拖进废纸篓（不影响已安装的 App）。

## 3. 第一次打开：绕过 Gatekeeper

这个 App 是用 ad-hoc 方式签名的（没有花 99 美元/年买 Apple Developer ID 做公证），所以 macOS 第一次打开时会拦一下，提示类似「"我的电视"无法打开，因为无法验证开发者」或「来自身份不明的开发者」。这是**正常现象**，不是 App 有问题，处理一次之后就再也不会跳出来了。

三种放行方法，任选一种：

**方法 A：右键打开（最简单）**
1. 在「应用程序」文件夹里找到「我的电视」
2. 按住 `Control` 点击（或右键点击）图标 → 选「打开」
3. 弹出的确认框里再点一次「打开」

**方法 B：系统设置放行**
1. 双击图标，看到拦截提示后点「完成」/关掉提示
2. 打开「系统设置」→「隐私与安全性」，往下滚动，会看到一行提示「"我的电视" 被阻止使用，因为它来自身份不明的开发者」
3. 点旁边的「仍要打开」，输入一次密码/Touch ID

**方法 C：终端命令（适合前两种都没弹出选项的情况）**
```bash
xattr -dr com.apple.quarantine "/Applications/我的电视.app"
```
执行后正常双击打开即可。

## 4. 打开后看到的是什么

App 自带一份公共 IPTV 源（500+ 频道），**不需要任何配置就能直接看**。如果有自己的订阅源要填，见 [README「首次配置订阅源」](../README.md#首次配置订阅源)。

## 常见报错排查

| 现象 | 处理 |
|---|---|
| 提示"无法打开，因为无法验证开发者" | 见上面第 3 步 |
| 提示"应用程序已损坏，无法打开" | 一般是下载/解压过程中文件被截断，重新下载 DMG；如果还是不行，用方法 C 的终端命令试一次 |
| 打开了但播不出画面 | 检查网络能不能访问订阅源地址；菜单栏「文件」→「重新加载」试试 |
| 翻译字幕一直转圈 / 报错 | 第一次用需要先下载模型（设置→翻译→模型库），确认下载完成且显示"已就绪" |
